## Executed checks and limits

`python docs/reviews/.verify-dependency-scripts.py` passed after correcting two harness assumptions (UTF-8 reading and the helper's actual log title). It extracts the actual workflow `run`/`runAndGet` definitions, substitutes Git Bash for the macOS `/bin/bash` path, and verifies failure status **43** propagates through `tee`/`cat` while preserving its log. It copies SideSign `build.sh` into a temporary directory and supplies a shell-function `swift` that fails with **47**: the wrapper returns 47, retains the build log and omits the completion line. It also runs Bash syntax checks for the helper/example catalogue and Python syntax compilation for workflow.py. No production build, filesystem export or credential operation occurs.

Scoped `git diff --check` passed for Shared, AltWidget, SideBackup, contribution/signing docs, Makefile, vendor workflow, and both dependency repositories. Narrow brace reconciliation passed for six touched Swift paths; **this is not Swift syntax or type checking**.

Swift is absent from PATH on this Windows host. Xcode/UIKit/WidgetKit/Network.framework/Darwin/native-device tests cannot run here. Every runtime limitation is retained above; fixes to pointer ownership, signing, backup replacement and device protocols need the targeted Apple-platform checks before claiming production/device verification. This report does not claim a new full source audit or that all suggested architectural improvements were implemented. Unsupported backend combinations now return explicit errors instead of successful no-ops; public compatibility DTOs and widget page-reset policy are documented choices.
